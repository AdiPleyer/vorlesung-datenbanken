# Vorlesung Datenbanken

Begleitmaterial zu meiner Vorlesung Datenbanken an der DHBW im Rahmen des IMBIT Studiengangs

## Database Content

[Database-Content](./Database-Content/) containes files to fill your existing database with table definitions and data representing the examples in this lecture.

## SQLite Database File

[Database-SQLite](./Database-SQLite/) has one .db file which is a SQLite file already filled with tables from section above.

1. download the .db file
2. download the SQLite Browser: https://sqlitebrowser.org/
3. Open the .db file with the browser and enjoy

## Examples Code

In [Lecture-Files](./Lecture-Files/) you can find files with SQL statements and also sample code as used in the lecture presentations. If you want to experiment, I recommend these instead of copying out of the PPTs, there might be some glitches with quotation marks result in syntax errors on the DB.

The name of the file or folder indicates to which part of the lecture it belongs.

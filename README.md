# Vorlesung Datenbanken

This repo contains material accompanying my database lecture. Main purpose is to offer some sample table definitions and data to excercise SQL statements.


## Database Content

[Database-Content](./Database-Content/) containes files to fill your existing database with table definitions and data representing the examples in this lecture.

## SQLite

[Database-SQLite](./Database-SQLite/) has one .db file which is a SQLite file already filled with tables and data


## DBFiddle

In the [DBFiddle section](./DBFiddle/) you can find files which are prepared for excercises on different topics.

## Lecture Code

In [Lecture-Files](./Lecture-Files/) you can find files with SQL statements and also sample code as used in the lecture presentations. If you want to experiment, I recommend these instead of copying out of the PPTs, there might be some glitches with quotation marks resulting in syntax errors on the DB.

The name of the file or folder indicates to which part of the lecture it belongs.

# Excercise with DBFiddle

Here, you can find files which are prepared for excercises on different topics using DBFiddle.

DBFiddle is an envorinment, in which you can freely experiment on different databases.

## How to

1. Call the website of DBFiddle: https://dbfiddle.uk
2. Copy & paste the respective file into the form
3. Extend by your own statements and enjoy

Recommendation: past each file in two separate fields of DBFiddle, this way it is better to handle

Currently, you have files for:
- [Hotels table](E1-Hotels-for-DBFiddle.sql)
- [Raum/Sitz/Preis tables](E2-Rooms-for-DBFiddle.sql)
- [Employees](C1-Employees-for-DBFiddle.sql) - this is a large one...

The files have been mainly testet on PostgreSQL latest version.
